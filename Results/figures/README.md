# Figures: what each chart shows and how to regenerate it

Run every plot script from the repository root (`python3 Results/figures/<script>.py`).
Data scripts write the CSVs in `Results/metrics/`; the sweep scripts resume from
checkpoints in `Results/metrics/.mc_sweep_checkpoints/`.

Channel for the BPSK trials: COST2100 fading ISI, memory 4 (16 trellis states),
120-bit words + RS(2 symbols), one pilot word per 25, decision-directed online
adaptation gated by the ECC (as in ViterbiNet).

| Trial (summary section) | Chart | Plot script | Data | Data generated by |
|---|---|---|---|---|
